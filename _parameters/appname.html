Mandatory

(string) This parameter allows ReliefWeb to monitor API usage and adapt it to user needs.

From 1 November 2025, API users will require a pre-approved appname. Request an appname by completing this short form. Appnames must be a combination of your (organization) name, purpose and random characters. Within one business day, the ReliefWeb will review your request and send you an email.

All of the examples in this documentation use apidoc. If you copy and paste examples into your own applications, you will need to change it.

Note that for both GET and POST requests, the appname parameter is sent in the url.
